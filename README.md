# CRUCIX // COMMAND OPERATIVE DASHBOARD

This is a web-based cyber tactical command center built for real-time threat monitoring and field telemetry tracking.

## Core Features
1. **Interactive Vector Continent Map:** Visualizes key global defense commands utilizing clean vector-based geography with mouse-wheel zoom and drag-pan mechanics.
2. **Organic Highlight Borders:** Continent highlighting dynamically follows geographic terrain polygon borders (removing rigid box grids).
3. **Defense Overlays:** Live feeds for undersea fiber tap alarms, naval carrier routes, and real-time ICBM trajectory warning simulation (active during DEFCON 1).
4. **Agent Telemetry HUD:** Monitored biological stats (BPM, temp, ammo) coupled with an HTML5 Canvas animated scrolling ECG heartbeat wave.

## Tech Stack
- React / Vite
- Tailwind CSS
- HTML5 Canvas API (highly optimized rendering)
- Lucide React

## Running Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Launch dev server:
   ```bash
   npm run dev
   ```
3. Compile production build:
   ```bash
   npm run build
   ```
